Cutting 99 features down to 25 made the model worse, not better

A linear regression trained on all 99 cleaned socio-economic features predicted violent crime rates across 1,994 US communities more accurately than the same model trained on 25–50 SVD principal components. Dimensionality reduction bought a smaller dataset here — it didn't buy a better one.

01 · Raw data wins, quietly

Linear regression on all 99 cleaned features scored 0.137 RMSE, beating every SVD-reduced version tried — 0.140–0.141 for 25–50 principal components. Fewer dimensions removed some noise, but it removed real signal along with it.

02 · Scaling isn't optional, it's the whole game

Without standardising first, PC1 alone "explained" 81% of the variance — an artefact of features sitting on wildly different raw scales (income vs. household counts), not real structure. After scaling, PC1's honest share fell to 25%.

03 · One-hot encoding cost 1,828 columns for nothing

Encoding the community-name field ballooned the feature space from 99 to 1,927 columns. After reduction to the same number of components, RMSE barely moved (0.139625 vs. 0.139627) — exactly as the dataset's own authors advised.

Methods

SVD three ways, scored the same way, on the same split

SVD was applied to three prepared versions of the data — raw/unscaled, standardised, and standardised-plus-one-hot — to see whether reducing 99 features to a handful of principal components would strip noise or strip signal. A plain linear regression (fit via the SVD/pseudo-inverse solution) was then scored on RMSE against a fixed 80/20 split for the original data and for 25- and 50-component versions of each reduced dataset, so every number in the comparison shares the same test set and the same model.

Standardising the data first turned out to be a precondition for SVD to mean anything: on unscaled data, PC1 alone captured 81% of variance simply because a handful of features (population counts, absolute dollar amounts) sit on much larger raw scales than the rest — not because the data has one dominant underlying factor. Once scaled, PC1 dropped to a believable 25%, and its top loadings (median family income, % receiving public assistance, % of kids with two parents) matched real, interpretable structure — later confirmed by scatter plots showing PC1 tracking median family income and PC2 tracking recent immigration. The honest limitation is the headline comparison itself: RMSE differences between 0.137 and 0.141 are small in absolute terms, and a single fixed train/test split (no cross-validation) means this ranking could shift a little with a different seed. What it does support cleanly is the direction of the effect, replicated across both 25 and 50 components and with or without one-hot encoding: reduction cost accuracy, it didn't add any.
